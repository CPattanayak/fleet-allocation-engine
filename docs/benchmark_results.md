# Benchmark results

Generated by `python scripts/benchmark.py`. Each row is the mean over 8 seeded Bengaluru scenarios from the fleet-service generator. G = Greedy (urgent-first, earliest-deadline, cheapest truck). H = pure batched Hungarian. H60 = batched Hungarian with a 60-min look-ahead (the default). Objective = soft cost of all assignments + priority-scaled penalty for every unserved order (lower is better). 'Best objective (count)' = in how many seeds that variant achieved the lowest objective (ties count for all). Runtimes use the SciPy solver.
